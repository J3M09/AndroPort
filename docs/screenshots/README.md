# Screenshots for the AndroPort README

The README references these files from `docs/screenshots/`:

- `01-main-phone-tab.png` — main window, Phone tab, no device detected

- `04-transfer-center.png` — Transfer tab (`Transfer center`, destination, push/pull)
- `05-activity-log.png` — Activity tab (`Activity log`, `Export log`)

## How to add them

1. Take screenshots at 100% scale, dark theme, window maximized if possible.
2. Crop the Windows taskbar out unless it is intentional.
3. Save as PNG with exactly the names above into this folder.
4. Commit and push — GitHub will render them in `README.md` automatically.

The five screenshots were provided with the original request (main window, About, Help, Transfer, Activity). Re-export those images to these filenames.
